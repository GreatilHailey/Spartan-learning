## 成果
- 利用 `cargo new Day11/rust_tests --lib --vcs none --edition 2021` 创建了测试用库项目
- 利用 `cargo test` 进行了断言测试
- 在 `Day11/rust_tests/src/lib.rs` 中建立了两个 `#[test]` ，分别对 `satisfies(3, 4, 12)` 和 `!satisfies(3, 4, 13)` 进行了断言
- 最终运行了两个测试，结果为 `2 passed; 0 failed` ，分别确认满足约束时返回 `true` 、不满足时返回 `false`

## 对今天的理解：
- 通过参数 `--lib` 创建库项目，不要求提供 `main` 函数；本次在库项目中编写测试，但可执行程序项目也可以编写测试
- 通过 `#[test]` 告诉 Rust 下面是测试函数
- `assert!(条件)` 用来判断 `条件` 是否成立；若成立，则 `passed` 并继续执行，否则则触发 `panic` 后判定 `failed` 
- 在普通库版本里被标有 `#[test]` 的函数不会参与编译，所以此次测试中运行 `cargo test` 后会显示 `satisfies()` 没有被调用
- 在函数名后的 `!` 的作用是表示此处调用为宏，而不是普通函数；宏可以理解成在编译时，根据不同的传入的内容生成相对应 Rust 代码的工具
